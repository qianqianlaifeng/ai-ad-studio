①先配接口（第一次使用必做）

这个工作台不绑定服务商，文本、图片、视频三个模型都接你自己的接口和密钥。配置一次，之后一直有效。

  1. 点右上角 ⚙ 设置（或左侧导航「API Key」）打开设置面板。
  2. 如果用的是国内 Agnes AI：点 「一键填入国内配置」，Base URL、接口路径、模型名会自动填好，你只需要粘贴自己的 API Key。
  3. 在 文本模型 / 图片模型 / 视频模型 三个标签页里各粘贴一次 API Key（三个标签页是独立的，不会互相覆盖）。
  4. 点 「保存设置」。右上角显示模型名、左下角圆点变绿，就说明配置成功了。
最容易错的一点：三个模型名必须各填各的，不要互相复制。文本、图片、视频的模型名是不同的三个名字，混填会直接报「模型不存在」。
标签页国内 Agnes 该填什么作用
文本模型agnes-3.0-flash写叙事提示词、视频提示词
图片模型agnes-image-2.5-flash生成主视觉图、分镜宫格图
视频模型agnes-video-2.5-flash图生视频 / 文生视频

密钥只保存在你自己浏览器的本地存储里，不会上传到任何服务器。换电脑或清缓存后需要重新填一次。

②最快出片：一键生成全部

不想一步步点，用这个。整条流水线自动跑完。

  1. 在模块 1 产品信息 里填产品名、核心卖点、主色、场景、风格、受众（已经预置了一套示例，可以直接改）。
  2. 点页面顶部 「✦ 一键生成全部」。
  3. 进度条会依次显示：叙事提示词 → 主视觉图 → 视频提示词 → 视频。中途不用管。
  4. 跑完后：图片在 6 追画区域，视频在 10 视频生成历史，点缩略图可全屏预览。
任何一步失败，进度条和提示都会写清卡在哪一步、失败原因是什么。先按 ⑦ 常见问题 对照一下，大多数是限流或密钥问题。

③分步精细控制（想改画面用这条）

每一步都能看到结果、手动改，适合对画面有具体要求的时候。

1 产品信息→2 生成叙事提示词→3 提示词预览（可手改）→4 图像生成→7 生成视频提示词→9 视频生成
  1. 模块 2 点「◇ 生成叙事提示词」，模块 3 会输出图片提示词。这一段可以直接编辑，改完再出图。
  2. 模块 4 选比例和数量，点「✧ 开始生成」。
  3. 模块 7 点「✦ 生成视频提示词」，模块 8 输出 A-roll 口播 + B-roll 镜头的完整提示词。
  4. 模块 9 选参考模式、时长，点「▶ 生成视频」。
模块 3 和 8 的提示词是整站的「方向盘」。想换风格、换卖点表达，改这里比改任何设置都有效。

④分镜宫格图 → 用宫格图出视频（推荐）

这是让视频「按分镜走」的关键功能。宫格图相当于给模型一张完整的分镜脚本。

  1. 到模块 5 分镜宫格图，选规格：2×2 四格 / 3×2 六格 / 3×3 九格（默认九格，最完整）。
  2. 点 「▦ 生成分镜宫格图」，约 10–15 秒出图。
  3. 九格会按固定分镜顺序自动排：产品空镜 → 痛点 → 使用 → 质感细节 → 推荐 → 效果 → 场景全景 → 手持产品 → 产品英雄。每格左下角的编号和镜头名是网页叠上去的，图里本身没有任何文字，所以不会出现乱码。
  4. 点宫格图下方的 「设为视频参考图」。模块 9 会自动切成：参考模式 = reference（参考图），参考图来源 = 分镜宫格图，视频比例也会跟着宫格图走。
  5. 到模块 9 点 「▶ 生成视频」。提示词会自动追加「不要九宫格分屏、不要画格边框」，保证出的是单一连续画面而不是拼贴。
参考模式含义什么时候用
纯文本只用文字描述，不传图没有参考素材、快速试效果
reference 参考图把图当「视觉与分镜基准」，模型参考构图和内容重新生成用宫格图出视频就选这个
keyframe 首帧把图直接当视频第一帧，之后画面从这一帧动起来只有一张产品图、想让画面从它开始动
宫格图如果一次不满意，直接再点一次生成即可，每张都会进「追画区域」，可以对比挑一张当参考。

⑤生成 30 秒广告

国内视频接口单次一般最多 10–12 秒，所以 30 秒是「分段生成 + 本地合并」做的。

  1. 点页面顶部 「⚡ 一键生成 30S 广告（国内）」。
  2. 系统会自动：生成叙事提示词 → 生成主视觉图 → 生成视频提示词 → 分 3 段各 10 秒依次生成 → 本地拼成一条 30 秒成片。
  3. 成片保存在项目的 outputs/ 目录，同时视频历史里能看到 3 个分段。
重要：30 秒合并必须在本地运行。视频下载和 ffmpeg 合并需要一个本地服务，所以要在项目目录执行 node server.js，然后访问 http://127.0.0.1:8787。直接打开线上网址时，合并这一步不可用（会提示需要本地运行），但单段视频照常能生成。

⑦常见问题

提示「图片接口未配置完整」

设置面板里图片标签页的 Base URL、API Key、模型名至少缺一项。点「⚙ 设置 → 图片模型」补齐后保存。

提示「免费用户 API 速率限制」或 429

这是服务商的每分钟请求数限制（免费账户通常很低，且未实名认证时更低）。等 1–5 分钟再试即可，不用改任何配置。连续快速点按钮最容易触发。

提示「视频队列已满 / video_queue_full」

这是服务商视频生成排队满了，与你的密钥和配置无关。换时段（深夜、清晨）再试成功率高很多。网站已内置自动重试，但无法绕过服务端排队。

视频只有 10 秒左右，怎么出 30 秒

国内视频接口单次上限一般 10–12 秒。用顶部「⚡ 一键生成 30S 广告」，它会自动分 3 段生成再本地合并。合并需要本地跑 node server.js。

生成的图片/视频在哪里

图片在模块 6「追画区域」，视频在模块 10「视频生成历史」。左侧导航的这两个入口上有数量角标。点缩略图可全屏预览，也可以直接右键另存。

我的 API Key 安全吗

密钥只写在你自己浏览器的本地存储里，不会发到本网站的任何服务器，源码里也没有内置任何密钥。但请不要在公共电脑上保存密钥，用完记得在设置里清空。

想换成可灵 / 即梦 / 硅基流动 / Runway 等其它服务商

设置面板里每一项都可以改：Base URL、接口路径、请求头、请求体模板、结果提取路径。请求体里用 {{prompt}}、{{model}}、{{duration}}、{{ratio}}、{{imageUrl}} 这类占位符，接口文档怎么写就怎么填。参考图模式的占位符是 {{imagesJson}}（图片 URL 数组）和 {{firstFrame}}（首帧图 URL）。

图片或视频加载不出来

多半是跨域（CORS）。本地运行时网站会自动走内置代理 /api/proxy；线上静态托管无法代理，某些服务商的资源链接会加载失败。这种情况建议本地运行使用。

教程随时可以从左侧导航「使用教程」或右上角「? 教程」再次打开。
